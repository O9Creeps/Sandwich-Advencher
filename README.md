# Sandwich-Advencher
API destination for the fetchers used in 'Sandwich Advencher Launcher!'. It will only work if you have Internet, but if you don't, then good luck.

## Plans
This player will not be like any other. I have come across many a project player in my time, especially on PenguinMod, but every single player doesn't involve a way to turn back without having to restart the entire program. This launcher, however, will be different! I plan to include a sprite within each project that lets you re-load back into the player itself!
